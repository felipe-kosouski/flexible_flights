# Devise Authentication Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the guest user pattern with full Devise authentication (register, sign in, sign out, password reset) and gate all search actions behind login.

**Architecture:** Add Devise to the existing `User` model by extending the `users` table with Devise columns. Remove the guest user pattern from `ApplicationController`. Lock down `SearchesController` with `before_action :authenticate_user!` and fix the IDOR in `show` by scoping the query to the current user.

**Tech Stack:** Ruby on Rails 8.1.2, Devise gem, PostgreSQL, Tailwind CSS, Hotwire/Turbo, RSpec

## Task 5: Gate SearchesController and fix IDOR

**Files:**
- Modify: `app/controllers/searches_controller.rb`

- [ ] **Step 1: Write the failing request specs first**

(Do this before changing the controller — see Task 9 for the full spec. For now, just verify the test file will be run. Skip to Step 2 if you prefer to write tests after.)

- [ ] **Step 2: Update SearchesController**

Replace the full contents of `app/controllers/searches_controller.rb` with:

```ruby
# frozen_string_literal: true

class SearchesController < ApplicationController
  before_action :authenticate_user!

  def new
    @search_intent = SearchIntent.new
  end

  def create
    @search_intent = current_user.search_intents.build(search_intent_params)

    if @search_intent.save
      search_run = @search_intent.search_runs.create!
      SearchRunJob.perform_later(search_run.id)
      redirect_to search_path(search_run)
    else
      render :new, status: :unprocessable_entity
    end
  end

  def show
    @search_run = current_user.search_runs
                               .includes(search_intent: :user)
                               .find(params[:id])

    return unless @search_run.completed?

    results = Search::Repositories::SearchRunRepository.load_results(@search_run)
    @presenter = SearchResultsPresenter.new(results, @search_run) if results
  end

  private

  def search_intent_params
    params.require(:search_intent).permit(
      :origin_airport, :destination_airport,
      :earliest_departure, :latest_return,
      :min_stay_days, :max_stay_days,
      :luggage_requirement, :max_stops
    )
  end
end
```

Key changes:
- `before_action :authenticate_user!` — no `only:` — guards all three actions
- `show` now uses `current_user.search_runs.find(params[:id])` — raises `ActiveRecord::RecordNotFound` (→ 404) if the search run belongs to another user

```ruby
# frozen_string_literal: true

require "rails_helper"

RSpec.describe "Searches", type: :request do
  let(:user) { create(:user) }
  let(:other_user) { create(:user) }

  describe "authentication guards" do
    context "when not signed in" do
      it "redirects GET /searches/new to sign in" do
        get new_search_path
        expect(response).to redirect_to(new_user_session_path)
      end

      it "redirects POST /searches to sign in" do
        post searches_path, params: { search_intent: { origin_airport: "JFK" } }
        expect(response).to redirect_to(new_user_session_path)
      end

      it "redirects GET /searches/:id to sign in" do
        search_intent = create(:search_intent, user: user)
        search_run = create(:search_run, search_intent: search_intent)
        get search_path(search_run)
        expect(response).to redirect_to(new_user_session_path)
      end
    end

    context "when signed in" do
      before { sign_in user }

      it "allows GET /searches/new" do
        get new_search_path
        expect(response).to have_http_status(:ok)
      end
    end
  end

  describe "IDOR protection on searches#show" do
    before { sign_in user }

    it "returns 404 when accessing another user's search run" do
      search_intent = create(:search_intent, user: other_user)
      search_run = create(:search_run, search_intent: search_intent)

      get search_path(search_run)
      expect(response).to have_http_status(:not_found)
    end
  end
end
```
